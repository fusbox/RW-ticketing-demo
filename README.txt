RangamWorks Ticketing System - Complete HTML UI Demo

How to run:
1. Extract the ZIP completely to a local folder.
2. Open index.html in Microsoft Edge or Google Chrome.
3. Keep all files in the same folder; styles.css and app.js are required.

Main demo pages:
- index.html                Ticket List
- create-ticket.html        Create Ticket (Contact Us-style form)
- manage-request.html       Ticket Details / Manage Ticket screen
- notes.html                Notes History with Edit/Delete flows
- attachments.html          Attachments
- communication-email.html  Communication - Email
- communication-sms.html    Communication - SMS
- view-history.html         View History
- candidate-details.html    Candidate Details

Current Ticket List behavior:
- Ticket List filters and sortable columns
- Candidate search by name/email/phone
- Referred to IT filter/column
- Colored ticket summary tiles
- History eye icon opens Status Updates matching each row's Current Status
- Create Ticket menu opens the Contact Us-style Create Ticket page

Important:
Do not open index.html directly from inside the ZIP preview. Extract the ZIP first.
